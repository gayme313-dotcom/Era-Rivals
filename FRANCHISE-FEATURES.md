# Dynasty HQ

Open **Front Office → Dynasty HQ** in any career. Existing saves gain the new systems when loaded. New careers offer rebuild challenges, historical-inspired starts, expansion drafts, season length, salary budget, and playoff-format choices under **Career options**.

These are lightweight management simulations across basketball, football, baseball and soccer. Ratings, contracts, box scores and historical benchmarks are game estimates. Current team rosters retain the existing dated roster snapshot. Prospects, free agents generated by the game, and coaches are fictional.

## Shared league details

Friends mode is an invite-only **eight-club, seven-round** casual format, separate from solo career saves and custom solo rules. Unclaimed teams are AI controlled. A commissioner advances only after every human manager submits a plan. The server owns outcomes and trades; browser clients cannot overwrite league state. Round/season checks and a row lock prevent double advances.

Players can send, accept, reject and counter player-for-player deals. Trading closes late in the season. New managers join before the first round. Standings determine the champion; ties use fewer losses then team name. Refresh to see friends' changes; updates are not pushed live.

Guest access requires no email. A random private player key is kept in browser storage; only its hash is stored on the server. Invite codes permit joining an unclaimed team and do not reveal player keys. Clearing storage loses that guest identity. No account recovery or cross-device identity transfer is offered in this version. Use nicknames and share invite codes only with intended friends.

Private tables have no client table grants and intentionally no RLS allow policies. Access is exclusively through the membership-validating RPC. The advisory about [RLS enabled with no policy](https://supabase.com/docs/guides/database/database-linter?lint=0008_rls_enabled_no_policy) is intentional default-deny protection on those private tables.

## Verification

Run from the repository root:

```sh
node tests/franchise.test.cjs
node tests/friends-client.test.cjs
```

The franchise suite includes the prior four-sport full-season, roster, save and injury checks plus 14 system groups: scenarios, custom rules, expansion, scouting/drafts, promises/mentors/chemistry/coaches, recovery, packages/clauses/forks, three-team swaps, free agency, news/clutch choices, injured-player stats, careers/recaps, league evolution and playoff champions.

`database/test-friends-leagues.sql` runs inside a rollback transaction. It tests invitation membership, unauthorized access, commissioner permissions, counters/ownership, readiness, duplicate rounds, seven-round seasons, next seasons and private table grants. No test league is kept.

Browser visual verification was unavailable in this session. Screen render checks and client/server transition tests passed; no claim of screenshot-based layout verification is made.
