# ERA RIVALS · PRO SERIES

**Four sports. One legacy.** An original independent browser sports game, created by Xavier Matos.

## Play

Launch [ERA RIVALS](https://gayme313-dotcom.github.io/Era-Rivals/) in a recent browser. Four playable arcade-style sports: basketball, American football, soccer and baseball.

- **PLAY NOW:** Real-time WASD movement; hold and release Space to shoot/throw/swing; J passes/switches; F defends or pitches; R restarts; P pauses. Each sport has unique scoring rules and CPU opponents.
- **MYPLAYER:** Custom name, position, physical measures, hairstyles, skin and uniform colors, body type, equipment colors and twelve sport-specific skill ratings. The preview updates as you customize.
- **MYCAREER:** College or pro careers (no high-school mode), a historical-era themed alternate-history starting selection, teams, XP, training, stats and local save progression.
- **FRANCHISE:** Customize your club colors, name, badge and scout fictional position-specific rosters.
- **CLASSIC MODES:** Preserved drafts and previous sim careers at [classic.html](classic.html). The previous visual version remains at [arena-v1.html](arena-v1.html).

## Graphics and scope

The game uses original procedural **WebGL 3D** rendering with lighting, stadium geometry and animated player models; browsers that block WebGL fall back to smooth high-DPI vector graphics. This is an **arcade sports prototype**, not a realistic 2K, Madden, EA FC or MLB The Show recreation. It contains no proprietary code, licensed logos, official real-player likenesses or complete verified historical rosters. The era selector is a fictional alternate-history theme, not authentic season-by-season rosters. Multiplayer is not included.

Career saves use browser `localStorage`. The new game attempts to import the previous Arena Edition save. No backend account is required.
