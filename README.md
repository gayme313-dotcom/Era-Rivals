# ERA RIVALS — PRO SPORTS LAB

An original, single-player, four-sport professional sports draft and coaching game by Xavier Matos.

## Game features

- **Four pro sports:** NBA basketball, NFL football, professional club soccer and MLB baseball. No high school or college paths.
- **Spin & Build:** Nine-round athlete builder. Draft a different player for each skill category to assemble one custom player profile.
- **Current Era and All-Time:** Separate recent-season and all-time fantasy pools.
- **Draft modes:** Classic, Blind, Daily, Weekly, Auction, Playoff, Team and Season Sim.
- **Squad builder:** Draft a full roster for a selected franchise.
- **Player and Manager Careers:** Choose position, height, weight, team, era and skill ratings. Physical choices affect build modifiers and simulated performance.
- **2D Live Coach:** Animated name markers and ball movement. Call plays, change tactics, queue substitutions, pause and adjust match speed.
- **Challenges and records:** Daily challenges, weekly gauntlets, Nine Squares, saved builds, badges, local standings, player records, Hall of Fame, past dailies and draft history.
- **Trophy Room:** Career history, local leagues, saved builds and JSON backup/export.

## How to play

1. Open `index.html` in a modern browser or host the repository on GitHub Pages.
2. Pick Basketball, Football, Soccer or Baseball from the dashboard.
3. Choose Spin & Build, Current Era, All-Time, or another draft mode.
4. Complete the draft. Results and saved builds are stored locally in your browser.
5. Start a professional Player or Manager Career.
6. Open Live Coach to call plays and manage the match from the sideline.

## Important limitations

- Player pools are curated historical references, not complete licensed league databases.
- Ratings, fantasy scores, match results, season outcomes and awards are original simulations, not official statistics.
- Global leaderboards, cloud accounts, remote friend leagues, payments and multiplayer require a backend and are not currently enabled.
- Official athlete photography, team crests and proprietary Hoop Factory / Endzone code or artwork are not included.

ERA RIVALS is an independent project and is not affiliated with the NBA, NFL, MLB, FIFA, Hoop Factory, or Endzone.

The game is single-player and uses browser localStorage. Export your save from the Trophy Room to back up progress.

## Deploy

Upload `index.html`, `sports-lab-icon.svg` and the `lab/` folder to the repository root. Enable GitHub Pages from the main branch / root.
