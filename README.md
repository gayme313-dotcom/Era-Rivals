# ERA RIVALS — PRO SPORTS LAB

A pro-only, original four-sport sports-management and fantasy draft browser game.

## How to play
1. Open `index.html` in a modern browser or host these files on GitHub Pages.
2. Select Basketball, American Football, Soccer or Baseball.
3. Choose Classic, Blind, Daily, Weekly, Auction, Playoff, Team, Season Sim or Live Coach.
4. Draft fantasy athletes from a limited curated player-season pool. Your draft results and awards save locally in your browser.
5. Create a professional Player or Manager Career (no high school or college). Height, weight, attributes and position influence your game ratings.
6. In Live Coach, select plays, tactics, substitutions, pause and match speed while circles move with the ball on a live court/field/diamond.
7. Open Trophy Room for records, local leaderboards, achievements, local friend leagues, nine-square grid, past dailies and JSON backup.

## Not yet available
- Verified full actual NFL weekly PPR box scores, comprehensive official historical team rosters, official athlete ratings
- Global leaderboards, cloud accounts, online private leagues, payments, remote multiplayer
- Licensed athlete photos, official crests, proprietary Hoop Factory / End Zone software

All player category ratings, fantasy performance values, and game results are **original editorial/simulated values**. Player names, team names and years are historical *references*, not complete season rosters. No official affiliation with NBA, NFL, MLB, FIFA, Hoop Factory, or End Zone.

The app is single-player and stores data in browser localStorage, so use the export button to back up your progress. The Daily seed uses the UTC date and is identical on devices with the same app data and date, but there is no worldwide ranking.

## Deploy
Upload index.html, sports-lab-icon.svg and the lab/ folder to the repository root. Enable GitHub Pages from the main branch / root.
